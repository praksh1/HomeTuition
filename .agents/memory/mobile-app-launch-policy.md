# Laptop web and installed mobile-app launch — 27 September 2026

The owner clarified that Fadko must work on laptops and installed Android/iOS apps. Phone browsers are the current testing path because the apps are not in the stores yet. After working app releases, the owner wants phone users directed to the installed app rather than continuing ordinary phone-browser usage. Laptop web must remain a full experience.

Do not block mobile browsers during this testing phase. Before any app-directed gate, verify both store listings, actual installed-app sign-in and classroom journeys, universal/app links and shared class/teacher links, sign-in recovery, and a safe route for people unable to install or open the app. A phone browser is still web, not evidence that native media works.

The current native build has Daily's WebRTC fork; configured LiveKit runs in browsers. A new native LiveKit build requires its own SDK, device tests and a versioned compatibility signal so older Daily builds keep working. Permanent account closure stays disabled while an existing native Daily path lacks enforceable media revocation.
