# Classmates can find each other without exposing moderation

Owner request, 24 September 2026: students should see other participants and be able to message privately. The public classroom directory is connected student display names and user ids only; it includes the viewer and excludes the teacher. The teacher-only floor rows, request times, microphone/camera grants, email and phone must never be included. Keep this explicit allow-list separate from moderation views and test both.

Opening a classmate composes privately inside a modal; it must not navigate away from or unmount the live call. Replies/history remain in Messages. This is not a second in-class chat or a complete inline DM thread.

Private messages and reactions independently check suspended accounts and (for two students) shared valid session enrollment. Refunded enrollment and cancelled classes do not qualify; test admission follows the existing server gate. Blocking is durable and belongs to its creator. The blocker cannot compose new private messages to the blocked person. The blocked person can still send, see their own sent messages, and react without an explicit blocked error, but these new messages and reactions are transactionally marked as suppressed for the blocker. Suppressed content stays absent from the blocker's thread, conversation list, unread count, notifications, email, realtime sync, and message-file access, even after unblocking. Existing visible private history remains accessible to its participants. Suppressed messages and reactions remain in private server storage as abuse evidence and must never be disclosed to the blocker through user-facing APIs. Send, react and block serialize on the same database pair lock; never trust a client button as authorization. If suppression storage is unavailable, message access fails closed rather than delivering content.

Safety & help in an existing conversation can block/unblock or send a private description of inappropriate behavior. The server creates an operator-visible Reported users support ticket linked to the reported user's id; the user receives a ticket reference. This does not automatically attach a private transcript, ban someone or expose their contact information. Operators may examine preserved evidence through appropriate private review processes. Any future age/guardian/consent policies need separate product review before public launch.
